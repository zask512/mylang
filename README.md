# MyLang — Beginners ke liye Programming Language

MyLang ek chhoti si programming language hai jo **Roman Urdu commands** ke saath likhi jaati hai. Ye un logon ke liye banayi gayi hai jo programming seekhna shuru kar rahe hain — taake concepts (variables, loops, conditions, functions) unki apni zaban mein samajh mein aayein, aur baad mein Python, JavaScript, ya koi bhi real language seekhna aasan ho jaye.

## ✨ Features
- `likho` — print / output dikhana
- `sunlo()` — user se input lena
- `agar` / `warna` — if / else condition
- `jabtak` — while loop
- `har X mein L` — for-each loop
- `kaam banao` — function banana
- `wapas` — return value
- `koshish` / `pakdo` — try / catch (error handling)
- `sach` / `jhoot` — true / false
- Lists: `["seb", "kela", "anaar"]`
- `#` se comment likhna

## 📝 Example Code

```
naam = "Ali"
likho "Salam, " + naam

kaam banao jama(a, b) {
    wapas a + b
}
likho jama(4, 7)

phal = ["seb", "kela", "anaar"]
har f mein phal {
    likho f
}
```
